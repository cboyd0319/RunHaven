# Clean state checklist

Use this before ending a non-trivial session.

- [ ] `scripts/python.sh scripts/check_harness_state.py` passes.
- [ ] Focused verification ran, or the skipped command, reason, risk, substitute,
  and closure trigger are recorded.
- [ ] `feature_list.json` uses one active feature and evidence-backed irreversible
  passing states.
- [ ] `PROGRESS.md` agrees on date, branch, active feature, status, blocker or
  unknown, and exact next action.
- [ ] Narrative output is in the evidence log or Git, not startup state.
- [ ] No secrets, machine-local paths, temporary debug files, stale generated
  reports, or undocumented partial work remain.
- [ ] `git diff --check` and `git status --short --branch` were reviewed.

Current ignored build caches may remain when they are useful and reproducible:
root `target/`, `ui/node_modules/`, `ui/dist/`, Playwright output, and Tauri
generated permission/schema directories. A stale nested `src-tauri/target/` is
not authoritative and should be removed only when it is clearly generated by
the current work. Never delete an unrelated user artifact to manufacture a
clean report.

A fresh session must be able to continue from `AGENTS.md`, `PROGRESS.md`, and
`feature_list.json` without reconstructing state from chat.
